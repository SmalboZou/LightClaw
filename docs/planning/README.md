# LightClaw Planning Documents

This folder contains the documentation set used to refine the original PRD into an implementation-ready specification for future development agents.

## Documents

- `01-gap-analysis.md`: what was missing or ambiguous in the original document
- `02-architecture-design.md`: target architecture, runtime boundaries, and major flows
- `03-technical-selection.md`: recommended language, framework, storage, messaging, and deployment choices
- `04-agent-development-guide.md`: constraints and implementation guidance for follow-up coding agents
- `05-implementation-roadmap.md`: staged delivery plan for the implemented MVP surface
- `06-local-runbook.md`: local setup, startup, and verification flow
- `07-browser-automation-plan.md`: browser-first automation expansion plan for weather and webmail tasks

## Usage

- Treat the root `PRO.md` as the canonical product requirements document
- Treat the files in this folder as supporting design and execution documents
- If product scope changes, update `PRO.md` first, then align the supporting documents
